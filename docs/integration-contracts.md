# Integration evidence

The lockfile pins the installed dependency graph, including ats-scrapers 0.3.0, python-jobspy 1.2.0 and Apprise 1.13.1. Master and tailored résumés use confirmed profile facts, the application-owned template and bounded local pdflatex compilation. Tailored fact selection uses the tested general LLM connection; automatic generation is off by default and controlled separately in Settings.

| Integration | Contract and evidence |
|---|---|
| ATS, directory, JobSpy | [Collection contracts](collection-contracts.md): live Ashby inventory and directory reads, source-inspected adapters, timeout and coverage tests. A live narrow Indeed query returned no rows, so its posting-field contract remains verified through fixtures/source only. |
| Matching and email | [Jev decisions](t06-jev-decisions.md), [transport safeguards](matching-alerts-contracts.md) and [encrypted email delivery](t14-email-alerts.md): current assessments and independent optional SMTP work with explicit uncertainty. |
| Résumé generation | [Master rendering](t11-master-resume.md) and [configured LLM drafts](t12-tailored-resumes.md): confirmed fact provenance, application-owned template, bounded compilation and PDF checks. |
| Optional Sheets | [Google authorization and sync](t15-spreadsheet-sync.md): stable IDs, explicit owned columns, reviewed inward application state and durable row journals; no local relay dependency. |

Live model inference, generated-template visual inspection, attachment receipt and the sustained latency trial are distinct acceptance gates. Passing offline tests does not establish those results.
